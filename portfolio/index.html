On-chain price oracle

Live · Testnet
Web3 · Smart Contracts
Problem
dApps need real-world price data, but traditional oracles are off-chain, subscription-based and trust-heavy.
Solution
Built a fully on-chain ETH price oracle on Ritual Chain testnet — the contract fetches live prices via native HTTP and JQ precompiles, executed in TEEs and verified on-chain. No off-chain servers, no oracle network.
Technology
Solidity · Ritual Chain (1979) · HTTP/JQ precompiles · Hardhat
Result
Live on testnet — HTTP 200, price stored on-chain in a single transaction, ~0.01 RITUAL per call. Open source with a public dashboard.
